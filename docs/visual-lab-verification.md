# CPU 工坊验证记录

本记录只描述浏览器实验台，不改变既有 FPGA / RTL / 实板证据。

## 检查入口

- `npm run test:visual`：Node 自带测试框架，24 项（CPU 12、逻辑电路 11、本地 HTTP 入口 1）。
- `npm run test:browser`：真实浏览器顺序运行 CPU 页面回归与电路拼接回归。
- `python -m unittest tests/test_run_all.py -v`：原项目编排器 3 项回归。

本次浏览器环境为本机 Microsoft Edge 的 headless 模式，使用 Playwright；桌面 1440 × 1080、窄屏 390 × 844。截图和 CPU 浏览器结果 JSON 写入 `build/visual-lab/`。

## 关键行为

| 路径 | 独立断言 |
|---|---|
| 默认 ADD32 定制单元 | 输入 7 / 5 → `$t1=12`、RAM[0]=12、RAM[4]=17 |
| 自行拼接 XOR | 拖入 XOR、连接三根线，4 行真值表全部正确；删除驱动线后输出变未知 |
| 安装 XOR32 | JSON 导入 → 导出相同网表 → 装入 CPU → `$t1=2`、RAM[0]=2 |
| 全加器 | 全部 8 行真值表；32 位 wrap 与中间 carry 均断言 |
| DFF | 反馈电路在两个上升沿交替输出 1 和 0；求值过程不偷偷推进时钟 |
| 流水线 | RAW 转发、load-use 一拍气泡、分支延迟槽、动态循环编号、完整回退 |
| 等待 | 默认程序 3 次访存，每次多等 3 拍，共增加 9 拍，结果不重复 |
| 程序示例 | Fibonacci 第 12 项 89；字节写把 0x12345678 变为 0x1234AB78 |
| 输入失败 | 汇编错误定位；无效 JSON 拒绝且保留编辑中的电路 |
| 交互 | 真正鼠标拖动、端口点击、删除、键盘、运行/暂停、换速、回退 |
| 窄屏 | CPU 与电路工坊均无整页横向溢出；电路画布内部滚动 |
| 本地服务 | 实际 HTTP 检查首页、JS MIME、越界拒绝、404 |

独立引擎审查额外使用随机软件参考程序、0–4 拍等待及随机加法向量核对。它是补充检查，不等同于 RTL golden trace 对照。

## 明确范围

普通指令和流水线模型的测试证明的是浏览器软件的行为。CUSTOM 没有加入 Verilog；Cache、CP0、板级显示和电气行为也不在本页模型中。完整范围见 [使用说明](visual-lab.md)。
