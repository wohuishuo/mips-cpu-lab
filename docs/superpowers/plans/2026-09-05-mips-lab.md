# MIPS CPU Lab Implementation Plan

This is the original execution plan. Final implementation names, measured results
and remaining physical observation limits are recorded in
[the capability ledger](../../capabilities.md) and [report](../../report.md).
The checklists below preserve planning history rather than current status.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete C01–C12, hardware tests, teaching visuals/video and public GitHub delivery.
**Architecture:** Independent tested RTL blocks, single-cycle reference, five-stage pipeline with exceptions, cache and SoC. Actual results drive all teaching artifacts.
**Tech Stack:** Verilog/SystemVerilog, Vivado/XSim 2019.2, Python, MARS, Tcl, FFmpeg.
**Spec:** ../../design.md

## Global Constraints

- Preserve all C01–C12 acceptance evidence from the source assessment.
- New RTL module contracts are exact in design.md.
- Work in D:/cpu/mips-cpu-lab on codex/build; original teaching materials are read-only.
- No old XDC; verify actual hardware before assigning pins or programming.
- Test failures, untested work and synthetic explanatory media are explicitly labeled.
- Public artifacts contain original content and properly attributed redistributable sources.

### Task 1: Single-cycle program execution (C02/C03/C04)

Files: rtl/core/single_cycle_cpu.v, tests/tb_single_cycle.sv,
tests/run_single_cycle.py, software/*.S, docs/single-cycle.md.
Consumes: exact single-cycle port contract. Produces: independently verified
instruction retirements, Fibonacci program and branch-delay-slot behavior.

- [ ] Write self-checking instruction/program tests first: zero register, signed/
unsigned comparisons, negative offsets, each shift, branch delay slot, JAL link,
load/store strobes, original Fibonacci arithmetic sequence.
- [ ] Run against absent/initial core to record failing evidence.
- [ ] Implement core and corresponding assembler/machine-code program fixtures.
- [ ] Compile/run XSim; compare state and trace with independent expectations.
- [ ] Review supported ISA and errors; commit only owned files after passing.

### Task 2: Cache subsystem (C10 module portion)

Files: rtl/cache/data_cache.v, tests/tb_cache.sv, tests/run_cache.py, docs/cache.md.
Consumes/produces: exact CPU/memory handshakes and counters in design.md.

- [ ] Write backing-memory scoreboard with random 0–7 cycle delays, byte writes,
same-set conflicts, dirty evictions, reset and parameter variants.
- [ ] Record failing test before implementation.
- [ ] Implement two-way tags/data/dirty/LRU with sequential refill/writeback.
- [ ] Run tests and inspect transaction stability, data persistence and counters.
- [ ] Review; leave CPU+cache integration as separate pending C10 evidence.

### Task 3: Peripherals (C01/C06/C11 module portions)

Files: rtl/peripherals/uart_tx.v, uart_rx.v, seven_segment.v, buzzer.v;
tests/tb_peripherals.sv, tests/run_peripherals.py, docs/peripherals.md.
Consumes/produces: exact contracts in design.md.

- [ ] Test UART 8N1 independent serial stimulus/monitor, reset, malformed stop,
continuous bytes; test digit scan and buzzer output frequency/disable.
- [ ] Record failing tests, implement modules, run XSim and self-review.
- [ ] Preserve board integration and physical demonstration as pending evidence.

### Task 4: Toolchain and hardware discovery (C01 preparation)

Files: scripts/discover_hardware.tcl, scripts/run_vivado.ps1, docs/hardware.md.

- [ ] Confirm Vivado/XSim version and part; read exact board manual/schematic.
- [ ] Query JTAG target/device without programming and discover UART port.
- [ ] Record actual identities and board pin evidence for new constraints.

### Task 5: Five-stage CPU and cross-check (C07/C08)

Files: rtl/core/pipeline_cpu.v, tests/tb_pipeline.sv, tests/reference_mips.py,
tests/run_cpu_regression.py, docs/pipeline.md.

- [ ] Freeze pipeline interfaces in a task-specific supplement based on working
single-cycle and cache handshake contracts before writing pipeline RTL.
- [ ] Generate independent expected instruction/state traces for deterministic
random and directed RAW/load-use/store-data/branch/zero-register programs.
- [ ] Implement five explicit stages, valid bits, bypass/holds/flushes, delay slot.
- [ ] Compare against software reference and single-cycle results; integrate
provided supported-subset function tests with transparent exclusions.

### Task 6: Precise exceptions (C09)

Files: rtl/core/cp0.v and pipeline integration; tests/tb_exceptions.sv.

- [ ] Test alignment, illegal instruction, overflow, syscall/break, interrupts,
eret, delay-slot BD/EPC, priority and suppression of younger side effects.
- [ ] Implement CP0 state and pipeline exception handling; run reference checks.

### Task 7: Complete SoC and physical proof (C01/C05/C06/C10/C11)

Files: rtl/soc/*.v, constraints/ees338.xdc, scripts/build.tcl,
scripts/program.tcl, software/demo.S, tests/board_test.py.

- [ ] Assemble verified ROM; integrate cache, MMIO, UART, display and buzzer.
- [ ] Simulate complete SoC with serial monitor and external memory scoreboard.
- [ ] Generate constraints only from confirmed board documentation; synthesize,
route and inspect reports before bitstream generation and programming.
- [ ] Verify UART telemetry and actual peripheral operation; retain raw evidence.

### Task 8: Teaching, media and publication (C12 and user media deliverables)
