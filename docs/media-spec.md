# Demonstration design

Use an original dark navy/cyan teaching style with large readable numerals,
clear signal names and restrained amber highlights. A native1280x720 telemetry
window receives real FPGA UART packets and shows actual PC, result, cycle and
retirement counters, displayed value and GPIO. It records timestamped packets
and commands; disconnected or invalid packets show an error instead of invented
results. An automatic30-second demonstration changes UART LED modes, beeps and
restarts the CPU while the telemetry keeps updating.

Record that actual window to video. Compose it with separately labeled original
datapath/hazard/cache illustrations based on verified traces, Chinese captions
and course-page references. Export useful frames and tightly framed video crops.
Physical board photographs or audible evidence may only be claimed when actually
captured. A drawn LED panel represents telemetry and is labeled accordingly.
