  1. 在 CPU 运行页输入 A = 7、B = 5，加载程序。
  2. 连续时钟单步：观察取指、译码、执行、访存、写回。

  5. 去电路工坊切换一个 32 位电路，装入 CPU，重新运行比较结果。

MODEL BOUNDARY

这里的动画由什么驱动？

由浏览器内的五级 MIPS 软件模型逐时钟计算。数据通路、寄存器、字节 RAM、转发、存储等待和一个分支延迟槽参与真实状态更新。

CUSTOM 是可替换的浏览器教学扩展。它没有改写仓库 FPGA 指令集。本页不模拟 Cache、CP0、异常处理、门传播延迟或板级电气行为；ADD32 展开图仅说明加法结构，其他定制网络在电路工坊查看。

上层图中的线表示阶段活动和逻辑连接，不是晶体管电压。DFF 的状态只在电路工坊的时钟操作时锁存。

需要什么软件？

使用实验台只需现代浏览器。本地运行安装 Node.js 后，在仓库执行 npm run lab，打开终端显示的地址。

本页不需要 Vivado 或专用 MCP。修改和验证实际 Verilog / FPGA 工程时，继续使用项目的 Vivado / XSim 2019.2 工具链。
